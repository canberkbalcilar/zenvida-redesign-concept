    Collections by need

    Each of these can be its own SEO landing page (e.g. "tired feet massage Madrid") and appears as the second column of the Rituals menu. A ritual can sit in several collections and still keeps one URL. The ritual-to-need matches are suggestions; confirm them with your therapists.

    Redirect map

    Add these as 301s in Wix under SEO → URL Redirect Manager. Ritual pages are already dynamic pages, so you only need to add a category field to the CMS collection and set the dynamic page URL to /rituals/{category}/{slug}.

    Lower-risk option

    If the ritual URLs (/all-rituals/…) rank well today, leave them alone. Move only the category pages and build breadcrumbs from the new tree. Breadcrumbs and internal links already carry most of the hierarchy signal.

    Check clicks per page in Search Console first: keep the URLs that bring traffic and move the rest.
